# absent from our directory entirely, so an employee banking here could not be

# b6f4a2c81e93 left this bank out ON PURPOSE and was right to: its own site was
# said to show 37 branches while the reference gave 27, five of them settlement
# endpoints, behind a JavaScript locator.
#
# Its /branch page renders one card per branch — `<h3>` name, address, and
# "Routing Number:" in the SAME card — so name and routing are paired inside one
# card (RULE 0), never matched across the page.
#
# ONLY 26 OF ITS 37 BRANCHES PUBLISH A ROUTING NUMBER. The page carries 37
# distinct `<branch>.branch@bgcb.com.bd` mailboxes but only 26 routing numbers;
# the other 11 (ashkona, ashulia, dupchanchia, haragach, kamrangirchar, karwan,
# khatunganj, namabazar, poddarbazar, rampura, tongi) appear as an email address
# with no branch card and no routing anywhere on the page. They are LEFT OUT
# rather than guessed — see BANK-BGCB-UNPUBLISHED-11.
#
# One 9-digit run on the page is NOT a routing: `255068880` is the bank's own
# phone number in a commented-out footer block. Same false-positive class as
# Al-Arafah's `015...` mobile numbers, which is why routings are read only from
# the labelled "Routing Number:" field.
#
# Districts come from digits 4-5 and were confirmed against each card's address.
# Two codes are ambiguous in our corpus and the address decides them: 27 (Dhaka
# vs Narayanganj) is Dhaka for all five, and 91 (Sherpur vs Sylhet) is Sylhet.
