# 678 printed rows collapse to 402 payable branches, because IBBL prints its
# ~259 SUB-BRANCHES against their PARENT branch's routing number. A sub-branch
# clears through its parent, so it is not a separate BEFTN destination and is not
# a separate row here -- the parent's name is kept. Making them rows would mean
# duplicate routing numbers, which the directory treats as one branch.
# ENDPOINTS EXCLUDED: the publication itself lists TRUNCATION POINT, AGENT
#   BANKING, REMITTANCE and three RTGS-* routings -- the same shape found in
#   Sonali's clearing list. A routing publication needs the same filter our own
#   scraped data does.
# ONE ROUTING DROPPED AS A TYPO: the PDF prints `Sonatola Bazar Sub-Branch,
#   Sonatola` as 125702988 while its parent SONATOLA is 125102988. Digits 4-5 are
#   the district: 10 is Bogura, where Sonatola is; 70 is Chapai Nawabganj, where
#   it is not. A sub-branch carries its parent's routing, so 125702988 does not
#   exist and adding it would put a fictitious branch in the picker.
# Districts are DERIVED from routing digits 4-5 against our own corpus rather
#   than read from the PDF's district column, which is unreliable: it prints
#   CHATTOGRAM against ALAMDANGA and CHUADANGA (both district 18), and spells
#   six districts in ways nothing else uses (CHAPAI NAWABJANJ, NAWABGANJ,
#   COX'S BAZAR, KHAGRACHARI, MOULVI BAZAR, NARSHINGDI). Every other row agrees
#   with the derivation apart from the DHAKA-NORTH/SOUTH split, which the
#   derivation collapses to DHAKA.
